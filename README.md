# 📝 ToDo List

Aplicação desenvolvida durante o curso de React da Rocketseat.

---

## 📌 Descrição

A aplicação consiste em um controle de tarefas (**To-Do List**) que permite ao usuário gerenciar suas atividades do dia a dia de forma simples e intuitiva.

---

## ✨ Funcionalidades

- ➕ Adicionar uma nova tarefa
- 🌐 Simular uma requisição HTTP
- ✅ Marcar e desmarcar uma tarefa como concluída
- 🗑️ Remover uma tarefa da listagem
- 📊 Visualizar o progresso de conclusão das tarefas

---

## 🚀 Conceitos Aplicados

Mesmo sendo uma aplicação simples, foram aplicados diversos conceitos importantes do ecossistema React:

- Gerenciamento de estado
- Imutabilidade do estado
- Listas e Keys no React
- Uso de Props
- Componentização

## ⚡ Quick Start

### Clone o repositório

```bash
git clone git@github.com:palhetabraian/ToDo.git
```

### Instale as dependências

```bash
pnpm install
```

### Execute o projeto

```bash
pnpm run dev
```

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos fundamentais do React, como manipulação de estado, componentização, passagem de propriedades entre componentes e renderização de listas, além da utilização do TypeScript para adicionar tipagem estática à aplicação.
